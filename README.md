# ProjectMars - Onboarding Task

Automated BDD tests for the ProjectMars web application using Selenium WebDriver, SpecFlow and NUnit in C#.

## Prerequisites

- .NET 6.0 SDK
- Google Chrome
- ProjectMars app running at `http://localhost:5000/`

## How to Run

Open `ProjectMars_OnboardingTask1.sln` in Visual Studio, build the solution and run all tests from the Test Explorer.

## Features Tested

- Authentication (Login/Logout)
- Languages (Add, Edit, Remove)
- Skills (Add, Edit, Remove)
